# FME Bookwriter - Codemagic Phone Build

Repository root is preconfigured for Codemagic.

1. In Codemagic, add `lootcheemaccinazFME/FlyMaccin-Ent`.
2. Use the repository `codemagic.yaml` configuration.
3. Select workflow `android-debug-apk` / `FME Bookwriter Android Debug APK`.
4. Start a build.
5. Download `app-debug.apk` from Artifacts after a successful build.

The OpenAI API key is not stored in GitHub or Codemagic. Enter it only inside the installed Bookwriter app Settings.
