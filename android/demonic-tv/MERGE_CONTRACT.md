# Demonic TV Merge Contract

Demonic TV is one capability with two packaging modes:

**Standalone:** applicationId `com.flymaccin.demonictv`.

**Embedded:** source/module imported by the parent. Pocket Potna/Demonic merged lineage retains its established parent identity; FME Universal ♾️ retains `com.flymaccin.fmeuniversal`. Do not create a second launcher when embedded.

Stable boundary:
`TvSource -> Receiver -> Surface/Audio/Input -> Parent TV host`

The DAW never owns Remote Play session state. The browser never owns Remote Play session state. Parent navigation may dock/fullscreen/PiP the same resident receiver without reconnecting.

No PS5 audio enters recording/rendering/export unless the user explicitly enables capture.
