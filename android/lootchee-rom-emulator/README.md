# LOOTCHEE OS Retro Emulator
First functional Android foundation.

Implemented: Android 26-36 shell; Storage Access Framework ROM import; persistent read permission; streaming SHA-256 identity; core-neutral EmulatorCore contract; Bluetooth/USB gamepad buttons and analog routing; pause/reset hooks.

Current hard gate: no emulator core binary is bundled yet, so ROM execution is not falsely marked complete. Next: integrate and license-audit the first real core, then video/audio/save plumbing.

ROMs and firmware are not distributed. Use user-owned dumps or homebrew/public-domain software.
