# Pocket Potna Remote v2

Clean standalone rebuild of the Pocket Potna remote/control surface. It preserves the historical production relay identity, persistent local pairing model, PS Remote Play handoff, and the PS5 / Browser / Downloads / Apps / Files / Cloud / Settings hub contract. Relay identity and ChatGPT one-time connector authorization are separate concepts.

This app launches Sony's Remote Play client when installed; it does not impersonate or reimplement Sony's protocol.
